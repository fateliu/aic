# 四分钟演示脚本

建议标题：从一句想法到一张社团插画。录制内容以软件实际响应为准，不伪装推理时长。未录制的视频不能写为已完成成果。

## 录制准备

在本机启动服务并准备已成功生成的样例。测试网络、模型权限和余额。隐去密钥、账户、学校/教师信息与无关历史项目。使用有权展示的原创题材。备好一张已保存图片应对网络异常，展示时说明它是此前运行结果。

## 分镜与讲解

| 时间 | 操作与画面 | 讲解要点 |
| --- | --- | --- |
| 0:00–0:25 | 展示最终插画，再回到创作台 | 社团创作者有想法，但常遗漏角色、构图、光照等绘图条件；工作台把中间设定变成可编辑记录 |
| 0:25–1:00 | 选择图片创作、DeepSeek、构图 Skill；输入原创机器人社团题材；点击优化 | 子 Agent 只负责整理需求。原始想法、补充建议和待确认问题可检查 |
| 1:00–1:35 | 展示并修改角色或留白位置，保存并勾选确认 | 明确显示哪些是用户给定、哪些是模型建议；修改会推进项目版本 |
| 1:35–2:05 | 交给主创 Agent；展开执行记录；检查并确认草稿 | save_creative / review_creative 是受限工具。检查保证结构，不替代人的审美判断 |
| 2:05–2:45 | 选择画面，确认单张费用，提交并展示任务编号、状态 | 调用真实百炼异步任务。等待较长时可标注时间跳转，不用假的进度冒充真实结果 |
| 2:45–3:15 | 图片出现、查看原图、下载 PNG、刷新后重开项目 | PNG 已保存在本地；项目保留实际提示词、版本和模型信息 |
| 3:15–3:45 | 讲漫画流程与角色参考；如已实测四格则展示成品 | 后续格可复用第一格参考，四格可合成；只有单图时不要播放模拟四格当生成质量证明 |
| 3:45–4:00 | 展示测试报告与未来计划 | 已验收本地流程与真实单图；下一步做四格质量对照、用户试用与对白排版 |

可用输入：

> 为虚构的机器人社团画一张迎新插画，两名原创大学生与两个原创小机器人围在工作台前组装小车。黄昏窗光，蓝紫与暖橙配色，日系动画风，右侧留白，画面不出现文字、学校名称、标志或已有动漫角色。

## 常见答辩问题

**为何拆子 Agent？** 将设定细化从创作编排中分离，让用户先检查模型补充信息；质量优势仍需要对照试验，不能只凭架构名称下结论。

**如何保持角色？** 文本角色锚点加已生成第一格的图像参考。模型仍可能漂移，可单格重生成；当前不承诺绝对一致。

**为何不是普通聊天框？** 可演示版本确认、固定 Skill、工具轨迹、远程任务恢复与本地图片管理。是否更省时、少返工要由试用数据支持。

**失败会重复收费吗？** 同一任务重复点击复用已有记录，提交不确定时停止自动重提，下载失败只重试下载。明确重生成才创建新请求，收费按供应商账户实际情况。

**动画做完了吗？** 当前只有分镜脚本，视频渲染未实现。
