# 用户试用与对照评估计划

状态：计划，尚未执行。本文没有实验结果，不可直接作为提升效果证明。

## 目标

验证设定细化是否提高提示词可用性，以及用户能否顺利完成社团插画/四格漫画。把模型效果与界面流程分开评价，避免只挑最好看的结果。

## 建议实验

选择 10 个原创校园题材，每题生成 A/B 两个版本：A 使用原始提示词，B 使用子 Agent 细化后、经过同等人工检查时间的提示词。固定图像模型、画幅与输出张数，记录所有尝试、失败、用户修改和实际费用；轮换生成顺序以减少顺序偏差。服务没有固定随机种子的保证，报告这一限制。

漫画额外比较同一分格脚本“仅文字角色锚点”和“文字锚点 + 第一格参考图”。不要将对照组故意删掉重要设定。实验会产生额外模型费用，开始前由团队确定预算与样本量。

由不知分组的评价者按 1–5 分独立打分：原意符合度、构图清晰度、关键限制遵从度；漫画增加角色外观一致性、前后动作连贯性。对分歧保留原始评分，不只报告平均值。小样本结论仅适用于这些题材。

## 用户试用

邀请 3–5 位实际有社团内容制作需求的同学，用相同任务各完成一次；记录开始至首次可用导出的耗时、提示词修改次数、生成次数、失败/恢复情况和使用障碍。收集同意后再引用反馈，可匿名记录。不要补写未发生的试点、用户或节省比例。

结果表建议字段：任务ID、组别、运行日期、模型、画幅、Skill哈希、人工修改说明、生成次数、成功/失败、总耗时、账户实际费用、评分、采用与否、匿名反馈。可把下列 CSV 表头另存填写：

```csv
task_id,group,date,text_model,image_model,ratio,skill_hash,edits,attempts,status,total_seconds,actual_cost,alignment,composition,constraint_following,character_consistency,adopted,feedback
```

## 决策标准

先修复导致任务无法完成的问题，再优化评价低分最多的约束类型。若子 Agent 在某类任务中没有收益，报告失败并调整提示词；若参考图限制了动作变化，保留关闭选项。提交材料展示全部样本数量和失败数，效果结论必须能回到原始记录。
