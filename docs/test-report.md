# 测试报告 v0.6

## v0.6 React 回归

`npm run test:ui` 通过 7 个 Playwright 用例，约 56 秒。代码位于 `tests/browser/studio.spec.ts`；每个用例先断言配置为模拟服务且 DeepSeek 不可用，再进行操作：

| 用例 | 实际验证 |
| --- | --- |
| 上传、折叠、四格与下载 | 2912 × 2056 角色图转换为 2048 × 1446 JPEG；损坏文件保留原参考；四格分别使用上传图、第一格、无参考、上传图；实际下载 1696 × 996 PNG；刷新重开保留结果 |
| 编辑与确认 | 未保存内容离开提醒；编辑后失效；旧图版本标记；自动参考变化清除费用勾选；修改提示词后草稿失效 |
| 创作类型 | 文字、图片、动画分镜分别为 1、1、3 个单元；图片可上传生成；文字和动画不显示生图入口 |
| 主题与响应式 | 红蓝记忆、换主题保留输入、随机装饰、背景预览/恢复；1440、1024、768、390、320px 无横向溢出 |
| 状态合并 | 图片响应不覆盖未保存草稿；拒绝其他项目、旧版本响应 |
| 中断与恢复 | 3 次查询 HTTP 失败后暂停；等待超过下一次周期不再自动查询；手动刷新恢复；生成提交计数保持为 1 |
| 旧项目兼容 | 旧版活动项目在 React 界面打开、修改、保存、重新确认，并实际下载含修改文字的 SVG 海报 |

另启动 `npm run dev:mock:ui`，在 5173 上实际创建项目、上传参考图、生成草稿，确认开发代理正常；伪造外站 Origin 返回 403。临时修改 CSS 后观察样式热更新与输入保留，再恢复原文件。人工查看晴空/赤日主题及手机参考面板截图，修正新面板边框细节。该轮没有调用付费模型，也不代表已验证真实角色还原质量。

本机运行 Playwright 使用已安装的 Chrome；CI 在 Ubuntu / Node 24 安装 Chromium。其余 Windows/Linux、Node 22/24 组合执行后端、类型和构建检查；本报告不代替远端 Actions 结果。

## v0.4–v0.5 浏览器验证记录

使用独立模拟服务器和同一张图片夹具完成四格操作，无额外模型计费：

- 未确认作品或未勾选费用时，生图按钮不可用；提交后费用勾选自动清除。
- 依次完成四格，每次一张；第 2–4 格请求关联第 1 格参考图。
- 四格合成并实际下载 1696 × 996 PNG，检查 PNG 头中的像素尺寸。
- 刷新、从历史重开，四张本地图片仍可查看。
- 390px 手机视口没有横向溢出，运行中没有捕获到 JavaScript 异常。

浏览器下载检查修正了测试工具使用的 Windows 路径格式；产品同时补充临时下载链接的生命周期处理。模拟四格中的图像内容相同，只验证操作、引用与合成，不证明真实四格叙事或角色质量。

红蓝主题另验证：切换角色与配色、刷新后记忆、切换时保留表单输入、随机装饰、背景对话框、减少动态效果设置。按 320、390、760、1024、1440px 检查真实 clientWidth，修复了手机历史栏撑宽导致页面缩放的问题。两张主视觉原图均成功加载，未捕获 JS 异常。

在仓库自带 `npm run dev:mock` 入口再次完成四格操作与 PNG 下载；配置确认 simulation=true，DeepSeek/Ollama 均不可用。新增项目标题、档案高亮、当前版本成功图片计数和阶段跳转也通过浏览器断言。跨站点切换后的补充截图脚本出现等待超时，随后在独立浏览器页面复核真实 PNG 加载通过；未将截图等待故障视为生图失败。

### v0.5 新增浏览器回归（模拟提供方）

使用真实上传控件选择项目内用户提供的角色 PNG（2912 × 2056），转换后保存为 2048 × 1446 JPEG。验证上传预览、白底转换、过小尺寸拒绝、损坏文件就地提示且保留原参考、费用确认重置、图片任务中的 referenceUploadId、漫画第二格切换 referenceJobId、刷新重开后的素材持久化。默认折叠、键盘空格展开、编辑保存后的折叠与分格摘要也通过断言。

补充验证第一格在后台完成后，自动参考来源由“无参考”变为“第一格”时，会清除已勾选的费用确认并禁用生成按钮。自动测试另外验证重复上传能修复丢失的本地素材，且不新增素材记录。

在 1440、1024、768、390、320px 检查无横向溢出；人工查看桌面与手机截图，红蓝主题均可用，未捕获 JavaScript 异常。最初键盘测试在未激活的无头标签页中无响应，激活测试标签并使用原生空格操作后通过，未给产品增加键盘劫持代码。

该次回归只使用模拟图片，不额外调用付费生图。证明参考图上传、存储、请求内容和交互链路；**尚未验证新上传参考图在真实模型上的角色还原质量**。

## 真实联调

项目“真实联调样例 · 星光机器人社团”：DeepSeek 提示词细化、主创工具调用、作品确认、万相 `wan2.7-image` 真实单张生成、任务查询、PNG 本地保存全部完成。实际结果为 **1280 × 720**，样例及去除服务凭据/临时下载地址的过程记录见 [examples](examples/README.md)。

另在重启后的真实服务器上检查了已存图片的桌面和手机展示，图片 naturalWidth 为 1280，没有横向溢出或捕获到的 JS 异常。这个检查没有再次提交生成任务。

只有 1 张真实生图样本，不能估计整体成功率、平均延迟或角色一致性。没有将提交阶段耗时误作整个绘图耗时，也没有报告未经账单核实的人民币费用。
