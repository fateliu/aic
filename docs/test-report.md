# 测试报告 v0.4

记录日期：2026-09-26—27。执行环境：Windows、Node.js 24.14.1、Chrome 无头浏览器。自动测试使用 `node --test`，不需要真实密钥。跨平台 CI 已配置，远端结果以 GitHub Actions 为准。

## 自动化验收

18 项测试通过（原有 12 项 + 图片服务 6 项）。测试代码位于 `test/`。涵盖：

| 范围 | 验证内容 | 方式 |
| --- | --- | --- |
| 原有活动与创作流程 | 输入校验、草稿、人工确认与导出 | 单元 / 本地 HTTP |
| 主子 Agent | 类型对应单元数、提示词 JSON、工具消息回传、失败边界 | 提供方模拟 |
| Skills / 版本 | 白名单和快照、过期版本与确认失效 | 单元 / 本地 HTTP |
| 百炼适配器 | 原生异步请求格式、n=1、图像参考；图片下载不附带 API Key，拒绝非 OSS 地址 | fetch 模拟 |
| 提交幂等 | 费用未确认、版本不符、重复点击、重复替换任务 | 持久化存储 + 计数断言 |
| 恢复 | 下载失败后仅重试下载，重新读取项目继续保存 PNG | 临时目录与模拟提供方 |
| 提交不确定 | 不自动重提；输入已有 task_id 找回结果 | 模拟断网 |
| 漫画引用 | 参考当前版本已成功图片，拒绝其他版本参考 | 存储与请求断言 |
| HTTP 行为 | 并发锁、PNG 下载类型、旧版本禁止提交 | 本地端口 |

“18 项”指 Node 测试用例数，不代表 18 次真实模型生成。测试只对已编码断言负责，不能推出不存在所有缺陷。

## 浏览器流程

使用独立模拟服务器和同一张图片夹具完成四格操作，无额外模型计费：

- 未确认作品或未勾选费用时，生图按钮不可用；提交后费用勾选自动清除。
- 依次完成四格，每次一张；第 2–4 格请求关联第 1 格参考图。
- 四格合成并实际下载 1696 × 996 PNG，检查 PNG 头中的像素尺寸。
- 刷新、从历史重开，四张本地图片仍可查看。
- 390px 手机视口没有横向溢出，运行中没有捕获到 JavaScript 异常。

浏览器下载检查修正了测试工具使用的 Windows 路径格式；产品同时补充临时下载链接的生命周期处理。模拟四格中的图像内容相同，只验证操作、引用与合成，不证明真实四格叙事或角色质量。

红蓝主题另验证：切换角色与配色、刷新后记忆、切换时保留表单输入、随机装饰、背景对话框、减少动态效果设置。按 320、390、760、1024、1440px 检查真实 clientWidth，修复了手机历史栏撑宽导致页面缩放的问题。两张主视觉原图均成功加载，未捕获 JS 异常。

在仓库自带 `npm run dev:mock` 入口再次完成四格操作与 PNG 下载；配置确认 simulation=true，DeepSeek/Ollama 均不可用。新增项目标题、档案高亮、当前版本成功图片计数和阶段跳转也通过浏览器断言。跨站点切换后的补充截图脚本出现等待超时，随后在独立浏览器页面复核真实 PNG 加载通过；未将截图等待故障视为生图失败。

## 真实联调

项目“真实联调样例 · 星光机器人社团”：DeepSeek 提示词细化、主创工具调用、作品确认、万相 `wan2.7-image` 真实单张生成、任务查询、PNG 本地保存全部完成。实际结果为 **1280 × 720**，样例及去除服务凭据/临时下载地址的过程记录见 [examples](examples/README.md)。

另在重启后的真实服务器上检查了已存图片的桌面和手机展示，图片 naturalWidth 为 1280，没有横向溢出或捕获到的 JS 异常。这个检查没有再次提交生成任务。

只有 1 张真实生图样本，不能估计整体成功率、平均延迟或角色一致性。没有将提交阶段耗时误作整个绘图耗时，也没有报告未经账单核实的人民币费用。
