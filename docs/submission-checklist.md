## 答辩重点

把“校园社团一张宣传插画或一个四格故事”作为主场景，演示改设定、确认版本、取回真实图片的连续操作。以实际执行轨迹解释子 Agent 做了什么、主 Agent 调用了什么工具、用户在哪一步介入。

差异点应落到可见机制：补充设定显式列出，技能内容随项目固定，第一格作为后续格参考，提交未知时不自动重扣费。它们是本项目的产品与工程设计，尚不能据此宣称行业领先或画面质量提升了某个百分比。

开发使用了 AI 编码辅助；团队应据实记录成员的设计、修改、测试及理解情况，并核对赛事对辅助工具与原创贡献的要求。不得将外部服务模型写成自行训练，也不要将功能模拟当作真实用户案例。

## 提交前由团队完成

确认报名信息、匿名要求和最终模板；实际体验并能解释核心代码；完成真实四格和用户试用；录制视频，制作 PDF；检查文件大小与分享有效期。当前仓库提交不等于已向赛事系统报名或交稿。
