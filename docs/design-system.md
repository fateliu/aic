# 晴空 / 赤日视觉系统

方向：P3R 风格参考下的角色海报与创作工作台。使用大号斜体字、斜切色块、窄边框、醒目的编号，搭配清楚的白色输入区。取代旧版蓝紫渐变、圆角玻璃卡片。

## 主题与角色

| 配色 | 视觉特征 | 图片 |
| --- | --- | --- |
| 晴空 sky | 亮蓝、深海军蓝、青色点缀，冷白底 | 用户提供的第一张角色图 |
| 赤日 flare | 红色、深棕黑、暖黄点缀，暖白底 | 用户提供的第二张角色图，CSS 调整展示色相 |

两张源 PNG 保持原文件内容，用 CSS 展示图版右侧的大头像。桌面和手机分别调整裁切，角色仅进入主视觉，不压在表单或作品上。

顶部按钮切换主题，浏览器 localStorage 记住选择；保存不可用时当前会话仍可切换。`public/theme.json` 的 palette 设置默认值，heroSkyImage / heroFlareImage 指向同目录下的合法图片路径。

## 随机性的范围

“换构图”改变字样角度、人物微小偏移和斜切变化，控制在有限区间。主题随机装饰不清空用户输入、不移动表单按钮、不变更作品参数，也不会触发模型请求。用户的系统设置为减少动态效果时，停用入场和装饰动画。

## 工作台布局

桌面侧栏用于项目切换，中间保留灵感输入，右侧放 Agent 流程与作品。手机端档案变为横向列表，输入、结果、Skills 顺序排列。当前项目有标题、版本和“提示词设定 / 创作稿 / 图片”快捷导航，当前历史记录高亮。

配色变量位于 style.css 顶部；响应式规则按 1600、1250、1020、760、470 等断点调整。调试时检查元素真实 clientWidth，不仅比较 innerWidth，防止手机自动缩放掩盖页面溢出。

## 图片替换

主视觉：替换 public/assets 的图片或修改 theme.json 对应字段。当前裁切适配用户提供的左右双栏图版；若换成单独人像，要同时调整 `.hero-character` 的 width / top / right。背景：使用页面背景按钮临时预览，或修改 backgroundImage 永久配置。

素材来源登记见 [素材表](qa/asset-register.md)。人物图用于用户指定的视觉参考皮肤，权利归原权利方，不能在参赛说明中称为本项目原创绘制。最终演示素材由团队核实使用范围或替换。
